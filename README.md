# Team Fortress 2 Takeover

**superhot** × Team Fortress 2 · visual · idea by the team

Bring Team Fortress 2 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned SUPERHOT into Team Fortress 2: BLU mercs in hats, crits, gear confetti and a sentry gun that freezes with time.

## Install

Install BepInEx 5 (x64) into your SUPERHOT folder, then copy this mod's BepInEx\plugins\SigfMix folder into BepInEx\plugins. Start SUPERHOT, load an endless level and play: every enemy is now a hatted BLU mercenary.
